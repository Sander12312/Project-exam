# Barbershop E-commerce

A responsive e-commerce web application built with Vanilla JavaScript, HTML and CSS.

## Features

- Product feed
- Product details page
- User registration
- User login
- Shopping cart
- Checkout flow
- Success page

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
- Noroff API

# AI Usage Log

## How I used AI in this project

During this project I used AI as a support tool to help me improve and understand parts of my work.

### Branding and visual assets

I used AI to generate a simple placeholder logo for the project branding instead of using an existing company logo.

The final logo was selected and implemented by me.

### Brainstorming and structure

I used AI to discuss page structure, user flow, and how different pages should connect together.

Examples:

- Product page flow
- Cart flow
- Payment flow
- Success page flow

### Debugging

I used AI when I got stuck with bugs or when something did not work as expected.

Examples:

- Carousel not displaying correctly
- Cart price calculations
- Payment form validation
- Register/login error handling

### Accessibility improvements

I used AI to get feedback on accessibility and improve form structure.

Examples:

- Labels and input ids
- autocomplete attributes
- required fields

### UI and design improvements

I used AI for feedback on layout, spacing, buttons, and icon consistency to improve the visual quality of the website.

Examples:

- About section layout
- Cart button placement
- Success page button styling
- Footer icon consistency

### Brief review

I used AI to compare my project against the assignment brief to make sure all required features were included.

Examples:

- Share button
- Clear cart functionality
- Return to products button on success page

## Reflection

AI was mainly used as a support tool for feedback, debugging, and improving existing code. All final code was reviewed, tested, adjusted, and understood by me before implementation.
